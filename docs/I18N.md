# Language

Hireriv is in **English only**. This was the owner's decision (Steps 84 and 148): the Hindi and Telugu locale files were removed, and there is no language selector, no translated pages and no translated job listings.

## How the words are kept

- Every word the public pages, the apply form, sign-in and the main account pages show lives in `locales/en.json`, under stable keys (`t('job.applyTitle')`). Templates never hold those words themselves.
- `i18n.js` loads the file and gives each page `t()`, `th()` (with safe HTML values), `tv()` (job values such as types and modes) and plural rules for en-IN.
- A missing key shows the key itself, and `test/english-only.test.js` checks that only English is offered.
- `?lang=` in an address and an old `hr_lang` cookie are ignored: pages are always `<html lang="en">`.

## Job seekers' own languages

A candidate's profile still lists the languages they speak (for example Hindi or Marathi), because employers ask for them. That is profile information, not the site's language.

## If languages are wanted again later

The code to translate the site (the language selector, translated job listings with employer approval, search words in other scripts) still exists in `i18n.js` and `job-translations.js`, but is switched off because `LANGUAGES` in `i18n.js` lists English only. Bringing a language back means adding it to that list, adding its locale file with every English key, and having a native speaker review it. Ask for it as a new step.
